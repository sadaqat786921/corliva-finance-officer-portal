# CORLIVA · Finance Officer

Clickable prototype of the CORLIVA Finance Officer portal (Omar Haddad, Royality Home Care, North and South Branch): billing from approved visits, invoices, payments, money owed, timesheets and payroll exports.

Sign in with any email and password, then security code **246810**.

```
npm install
npm run dev
npm run build
```

See `AGENTS.md` for the screens, rules and demo story.
